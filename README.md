## 探索项目｜Selected work

我做的东西可以分成三堆。不按"技能/应用"这种没营养的分法，按它们到底在跟你说什么话来分。

### 一、给 AI agent 用的手艺

这几个都是喂给 AI agent 的技能。共同点：动手之前先把事想明白，活儿干完能接得住、传得下去。

**[巨人之肩｜Giants' Shoulders](https://github.com/TongyiDai/giants-shoulders)**

> 如果说我看得更远，那是因为我站在巨人的肩膀上。

牛顿这句话被引烂了，但没几个人真照做。这个 skill 干的就是：你要造轮子之前，它先替你上网翻一遍——有没有人做过、谁做得好、坑在哪、你跟他们到底差在哪。查完给一个明确结论：直接用、改一改、还是真得从头造。不让你在别人踩过的坑里再摔一次。

**[薪尽火传｜Agent Relay](https://github.com/TongyiDai/xinjin-huochuan)**

> 指穷于为薪，火传也，不知其尽也。

庄子两千年前就把这事说透了：柴烧得完，火传得下去。AI agent 也一样——额度会用完，上下文会被压缩，客户端说换就换。这个协议让一个 agent 停下时，把真正的工作现场交给下一个：做到哪了、哪些事实可信、产物在哪、谁接棒、什么算完成。传的不是一段聊天摘要，是能验收的整个活儿。Codex 交给 TRAE，TRAE 交给 Claude，谁都不用从头再来。

**[蓝色波点｜Geometry Board](https://github.com/TongyiDai/geometry-board-skill)**

> 这张图要让读者一眼理解什么？

大部分人画图是先动笔、边画边想，画出来一堆框和箭头，自己都说不清重点。这个 skill 反过来：先回答上面那句话，想不清就不画。想清楚了，再用最克制的几何——点、线、面、一个蓝点——把那一个核心判断摆出来。一图一意，多一个元素都是噪音。

**[中文老师｜Chinese Teacher](https://github.com/TongyiDai/chinese-teacher)**

> 不是"帮你写得更正式"，而是让文档有判断力、有人味、能推动决策。

中文工作文档有两种死法：一种冷得像翻译件，读完不知道谁写的；一种水得像正确的废话，读完不知道要干嘛。这个 skill 治的就是这两种病。它不把你的话改得更官腔，它让文档里有个活人在说话——敢下判断，有观点，读完知道下一步做什么。

### 二、时间是能算出价钱的

我不信"时间宝贵"这种空话。宝贵就该有个数。这两个都是把看不见的时间，换成看得见的数字。

**[时间就是金钱｜AI's time is money](https://github.com/TongyiDai/agent-value-ledger)**

> 记录的核心单位不是"调用了几次 AI"，而是"完成了一项什么工作，并留下了什么结果"。

大家都在吹 AI 提效，但很少有人能说清到底省了多少。这个 skill 让 agent 自己记账：干完一件事，估它替你省了多少人工时间，按你的时薪折算成钱，记进一本本地 Excel。它只报保守值，每笔都要有证据，宁可少算也不吹牛——因为夸大的数字，比不记还糟。

**[窝囊费计算器｜Time is Money](https://github.com/TongyiDai/timeismoney)**

> 上班为了下班，摸鱼为了快乐。把看不见的时间，变成看得见的快乐数字。

一个不装正经的小工具。你一上班，它就开始按你的工资实时给你算钱——这一秒你挣了多少。道理很朴素：既然时间就是钱，那摸鱼的每一秒，都是你从老板那儿挣回来的窝囊费。看着数字往上跳，多少有点安慰。

### 三、公司拿 AI 筛你，你也得有自己的 AI

**[职业操作系统｜Career Ops](https://github.com/TongyiDai/career-ops-zh)**

> 公司用 AI 筛候选人。我们把 AI 交给候选人，让候选人更清醒地筛机会、讲清自己、管理职业选择。

求职这场仗现在是不对称的：招聘方用 AI 扫简历、排候选人、写面评，你还在一个个手动海投。这个东西想把天平掰回来一点——它是候选人自己的 AI 作战室。不是帮你把简历润色得更漂亮，而是帮你先判断这个岗位值不值得投，再想清楚怎么讲自己的故事。少投垃圾岗位，少走弯路。
