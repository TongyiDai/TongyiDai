## 探索项目｜Selected work

按它们解决的问题分三类。

### 一、给 AI agent 用的技能

- **[巨人之肩｜Giants' Shoulders](https://github.com/TongyiDai/giants-shoulders)** — “如果说我看得更远，那是因为我站在巨人的肩膀上。”开工前先上网查有没有人做过，再决定复用、改造还是从头造。
- **[薪尽火传｜Agent Relay](https://github.com/TongyiDai/xinjin-huochuan)** — “指穷于为薪，火传也，不知其尽也。”让一个 agent 把可验收的工作现场，可靠交接给下一个。
- **[蓝色波点｜Blue Dot](https://github.com/TongyiDai/geometry-board-skill)** — “这张图要让读者一眼理解什么？”把复杂内容提炼成一张“一图一意”、克制的几何画板。
- **[中文老师｜Chinese Teacher](https://github.com/TongyiDai/chinese-teacher)** — “全世界都该学中国话，AI 也不例外。”写中文工作文档，让它有判断力、有人味、能推动决策。

### 二、把时间换成看得见的数字

- **[时间就是金钱｜AI's time is money](https://github.com/TongyiDai/agent-value-ledger)** — “完成了一项什么工作，并留下了什么结果。”让 agent 自己记账，把它省下的时间保守折算成钱、每笔有据可查。
- **[窝囊费计算器｜Time is Money](https://github.com/TongyiDai/timeismoney)** — “上班为了下班，摸鱼为了快乐。”按你的工资实时算钱，把摸鱼的每一秒变成看得见的窝囊费。

### 三、公司拿 AI 筛你，你也该有自己的 AI

- **[职业操作系统｜Career Ops](https://github.com/TongyiDai/career-ops-zh)** — “公司用 AI 筛候选人，我们把 AI 交给候选人。”候选人自己的 AI 作战室：先判断岗位值不值得投，再想清楚怎么讲自己。

---

> 把时间还给思考，把流程交给工具，把专业留给业务，把价值带给组织。  
> Give time back to thinking. Give workflows to tools. Keep expertise in the business. Bring value to the organization.
